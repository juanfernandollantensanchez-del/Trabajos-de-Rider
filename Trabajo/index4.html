Este es un texto de ejemplo para demostrar cómo funciona el texto en forma circular alrededor de una imagen usando CSS. Puedes escribir cualquier cosa aquí, como una historia, una descripción, un mensaje o simplemente texto de prueba. La idea es que el contenido rodee la imagen y tome la forma circular alrededor de ella, igual al ejemplo mostrado en clase. HTML y CSS permiten crear diseños modernos y creativos usando propiedades avanzadas como shape-outside.
